## ✨ What it helps with

| Feature | What it does |
| :--- | :--- |
| 👁️ **Image recognition** | Uses OpenCV and image templates to locate game interface elements. |
| 🔤 **Text recognition** | Uses Tesseract OCR to read on-screen text, timers, and resource values. |
| 🤖 **Automation routines** | Uses a Lua scripting engine to run routine tasks and interact through Android accessibility or root inputs. |
| 🫧 **Floating controls** | Provides an overlay for starting, pausing, and configuring the assistant. |
| 🌐 **Remote utilities** | Supports remote synchronization and logging features, depending on the build. |

## 🚀 Quick start

1. **Download the green assistant APK.** Open [Releases](https://github.com/AwaisX007/CoC-Free-Assistant/releases), read the release notes, and select the green version.
2. **Install it on Android.** Use a compatible Android device or emulator. If Android asks, allow installation from the app you used to download the APK.
3. **Enable the required permissions.** Allow Accessibility and Display over other apps when prompted. See the table below for details.
4. **Open the assistant and configure it.** Follow the options provided by your installed build, then use its floating controls to manage tasks.

### 🧰 Companion tool: NP Manager

**NP Manager (NP管理器)** helps with Android file management, game directories, and moving account files. Check the release notes for any steps that require it; it is a separate tool from the assistant.

## ⚙️ Permissions

| Permission | Purpose |
| :--- | :--- |
| ♿ **Accessibility Service** | Reads screen content and performs supported touch/swipe actions on non-rooted devices. |
| 🫧 **Display over other apps** | Shows the floating control bubble over the game. |
| 🔋 **Foreground service / battery settings** | Helps keep the assistant running in the background. |
| 🔓 **Root access — optional** | Enables direct input methods on rooted devices when supported by the selected build. |
